# 想定質問集ジェネレーター PRO — README

**バージョン：** v1.21.0（2026/06/06）
**形態：** 単一HTMLファイル（外部ライブラリ・外部通信なしで動作／AI機能はオプション）
**対象：** IT研修の講師・サブ講師（新卒研修・技術研修の運営担当）
**提供：** うさうさ研修工房 🐰

## 1. 概要 — このツールが解決すること

研修の現場では、受講生からの質問に「その場で」答える必要があります。同じ質問でも、文系・未経験の方と理系・経験者の方とでは、伝わる答え方が異なります。

本ツールは、**1つの質問に対して「文系向け回答（たとえで）」と「理系向け回答（技術用語で）」の2系統**を持つ想定質問集データベースを、**作る・引く・育てる**の3工程すべてを1枚のHTMLで完結させるものです。

設計方針は「人の頑張りではなく、仕組みで品質を守る」です。当日その場で考えない状態を事前に作り、研修で実際に出た質問をその日のうちにデータベースへ追記することで、運用するほど強くなります。

## 2. 動作環境

| 項目 | 内容 |
|------|------|
| 配布形式 | HTMLファイル1枚（ダブルクリックで起動） |
| ブラウザ | Edge / Chrome / Firefox / Safari の現行版 |
| ネットワーク | 不要（オフラインで全機能動作。AI連携時のみ通信） |
| インストール | 不要。研修会場の貸与PCでもそのまま動作 |
| データ保存 | ブラウザ内の自動保存＋JSONファイルへの手動バックアップ |

Excel出力は標準のOOXML形式（.xlsx）で、**Microsoft Excel・Googleスプレッドシート・LibreOffice**のいずれでも数式が動作することを検証済みです。

## 4. クイックスタート（3通り）

**A. まず触ってみる（30秒）**
①設定タブの「🎁 サンプル一式で試す」を押すと、ミニ想定質問集が入り、全タブを体験できます。

**B. 資料から一気に作る（時短）**
②タブの「📚 時短100問ジェネレーター」に研修資料（テキスト/md）を貼るか、キーワードを入力して実行。最大100問を自動生成・取込し、検索Excel・Notion用mdまで出力できます。

**C. 既存のExcelから引き継ぐ**
③タブで、お手持ちの想定質問集Excel（5シート構成）をファイル選択するだけで取り込めます。本ツールから出力したExcelの読み戻し（往復運用）にも対応しています。

## 5. AI連携（3モード・任意機能）

| モード | 用途 |
|--------|------|
| ☁️ Claude内で使う | claude.ai上で開く場合。設定不要（既定） |
| 🔑 APIキーで使う | ダウンロードしたファイルをローカルで使う場合。キーはメモリ上にのみ保持し、保存・送信は行いません（送信先はAnthropic APIのみ／ページを閉じると消去） |
| ✍️ 手動コピペ | AI接続なし。プロンプトをコピーして任意のAIに貼り付け、結果のJSONを③で取込 |

AI生成物について、**理系向け回答の技術的正確性と参考記事URLの実在確認は、必ず人間がレビューする**運用としてください。プロンプトには「不確かなURLを創作しない（検索キーワード案の形式にする）」旨の制約を組み込み済みです。

## 6. セキュリティ・運用ルール

- 個人情報・固有の案件情報・関係者の氏名は入力しない運用とします（出力物は役職名のみ：メイン講師／サブ講師 等）
- 表示系は全箇所でHTMLエスケープ処理を実施（外部データ取込時のスクリプト注入対策）
- CSV出力は数式インジェクション対策済み（先頭の = + @ - を無害化）
- Excel出力は制御文字の混入を除去し、ファイル破損を防止
- エスカレーションの一次報告先はメイン講師とし、サブ講師は単独判断しない前提の文言を各出力に記載

## 7. 品質保証（QA）

リリースは「商用テスト → バグ修正（最大5回）→ バグ0でバージョン刻印」のサイクルで行っています。v1.21.0時点の検証内容：

- 自動テスト：商用7フェーズ＋セキュリティ・境界値の計47項目、機能別スモーク約60項目
- Excel実計算検証：LibreOfficeで数式エラー0件（特殊文字・改行・引用符を含むデータで確認）
- Googleスプレッドシート互換：使用関数をIF/IFERROR/INDEX/MATCH/COUNT/SEARCH/ISNUMBER/MAXに限定し、互換チェック全項目合格
- 往復検証：出力Excelを本ツールで再取込し、全件一致を確認

## 8. よくある質問

**Q. 古いExcelしかない会場でも使えますか？**
検索の仕組みはFILTER関数を使わないINDEX/MATCH方式のため、旧版のExcelでも動作します。

**Q. データはどこに保存されますか？**
お使いのブラウザ内に自動保存されます。PCをまたぐ場合・確実に残す場合は⑩タブのJSONバックアップをご利用ください（編集したプロンプトやレッスン記録も含めて完全復元できます）。

**Q. AIなしでも使えますか？**
はい。検索・編集・出力・即答アシスタントの仮説提示はすべてオフラインで動作します。
