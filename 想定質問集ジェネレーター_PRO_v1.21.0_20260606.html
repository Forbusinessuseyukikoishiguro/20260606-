研修テーマの設定

📖 はじめての方へ — ツール全体の使い方（1分）
これは何？　受講生の質問に即答するための「想定質問集」を、作る・引く・育てる単一HTMLツールです。文系にはたとえで、理系には技術で答え分けます。たとえの世界観はデフォルトでうさうさラーメン店🍜（①で変更可・全問で1つに統一が鉄則）。

基本の流れ（タブの番号どおり）
① 🏠 テーマと世界観をきめる → ② 🤖 プロンプトをAIへ（🚀一気通貫／📚時短100問なら取り込みまで自動） → ③ 📥 JSONやExcelを取り込む → ④ ✏️ 技術レビューと追記 → ⑤ 🔍 当日はキーワード検索 → ⑥ ⚡ ふわっとした質問は仮説と30秒レシピ → ⑦ 🗂 出た質問を記録して⭐昇格 → ⑧ 📦 当日課題のサポート資料 → ⑨ 📤 Excel／JSONで持ち帰り → ⑩ 🧭 折り返しで中間チェック。

はじめ方は3つ：🎁 下の「サンプル一式で試す」（30秒で全機能体験）／📚 ②タブの時短100問（資料かキーワードから一気に）／📗 ③タブにお手持ちの想定質問集Excelをそのまま読み込み。

AI接続はページ右上で3モード（☁️Claude内＝キー不要／🔑APIキー＝ローカル用／✍️手動コピペ）。うさうさの約束：理系向け回答と参考記事URLの最終レビューは人間の仕事・固有名詞や個人情報は入れない・今日出た質問は今日のうちに追記🐰
📖 このタブの使い方
研修テーマ・たとえの世界観・カテゴリを入れて保存すると、🤖AIプロンプトに自動反映されます。世界観は1つに統一が鉄則。何もないときは「🎁 サンプル一式」で全タブを即体験できます🐰
🐰 ここで決めた内容が AIプロンプト に自動で埋め込まれます。たとえの世界観は1つに統一するのがコツです（質問ごとにバラバラだと、受講生の頭の中で絵がつながりません）。

📖 このツールの使い方（3分）

STEP 1：設定 → AIプロンプトをコピー
上の設定を入力し、「🤖 AIプロンプト」タブのプロンプトをコピーしてAI（Claudeなど）に送ります。質問・回答の中身はAIに作ってもらいます。
STEP 2：AIの出力（JSON）をインポート
AIが返したJSONを「📥 インポート」タブに貼り付けて読み込みます。読み込んだ内容はすぐ検索・編集できます。
STEP 3：自分の手で直す（ここが品質の分かれ目）
「✏️ 編集」タブでセルを直接クリックして書き換えられます。理系向け回答の技術的な正確性レビューだけは人間の仕事です🐰 研修当日に出た質問も、その日のうちに追記しましょう。
STEP 4：保存・Excel出力
「📤 保存・出力」からJSON（このツール用の保存形式）とExcel（5シート構成・検索数式入り）を出力できます。ブラウザにも自動保存されます（対応環境のみ）。

AIプロンプト自動生成

🐰 設定タブの内容を反映したプロンプトです。そのままコピーしてAIに送信→ 返ってきたJSONを「📥 インポート」へ。
AIはとても優秀ですが、細かい仕様はしれっと間違えます。生成後のレビューは必ず自分の目で。

🚀 一気通貫 — このプロンプトでAIに作らせて → 取り込み → 確認 → 出力

🐰 上の①新規作成用プロンプト（編集版があればその内容）をそのままAIに送り、返ってきたJSONを自動で取り込みます。取り込み後はこの場でミニ検索して中身を確認し、ExcelやJSONをダウンロードできます。AI接続はページ上部のモード（☁️Claude内／🔑APIキー）を使います。フル生成は数分かかることがあるので、まずはお試し10問がおすすめです。

📚 時短100問ジェネレーター — 資料 or キーワードから一気に

🐰 受講生に学んでほしい資料（テキスト/md）を読み込ませるか、キーワードだけ入れて実行すると、想定質問集を最大100問つくって自動で取り込みます。100問は前半・後半の2回に分けて生成するので途切れにくい設計。終わったら下のボタンで検索Excel（Sheets対応）とNotion用mdまで一気にどうぞ。理系向け回答と参考記事URLの最終レビューは人間の仕事です！

どちらも読み込み後は「🔍 検索」での動作確認と「✏️ 編集」での技術レビューをお忘れなく🐰

⚡ 即答アシスタント — ふわっとした質問から仮説を立てる

📖 このタブの使い方
上段＝受講生の質問をそのまま入れて「🐰仮説を立てる」（DBから候補・オフライン）。下段＝⏱30秒レシピはDBが空でもOK：仮説・レベルを選ぶとステップバイステップ解説＋文系/理系の答え方＋参考記事まで生成。AI接続はページ上部のモード（☁️Claude内／🔑APIキー／✍️手動）で切り替え🐰
🐰 受講生の質問って、正式名称では来ません。「なんかコピーされるやつ」「あの黄色いの」——そんなふわっとした質問をそのまま入力すると、質問集DBから「本当はこれを聞きたいのかも？」という仮説を確からしい順に提示します。
仮説はあくまで仮説。受講生に逆質問で確認してから答えましょう（事実と所感を分ける🐰）。

🤖 AI相談

⏱ 30秒ティーチングレシピ — DBがなくてもOK

🐰 想定質問集をインポートしていなくても使えます。新人さん（受講生）のふわっとした質問と、あなたの仮説（任意）を打ち込むと、仮説確認 → レベル別ステップバイステップ解説 → 文系のたとえ／理系の技術 → 受講生にシェアできる参考記事まで、30秒で読めるレシピを作ります。
